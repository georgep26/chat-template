# Working Files

This folder is for local project working files that should not be committed.

Use it for:

- reports generated by coding agents, such as backend state reviews and implementation audits;
- temporary analysis files created while planning or debugging;
- `working_notes.md`, which is a stream-of-consciousness project note file and should not be deleted.

Generated reports should go here going forward instead of the top-level `docs/` folder. The folder contents are gitignored; this README is the only tracked file so the convention is visible in the repo.
