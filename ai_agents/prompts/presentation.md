# Presentation Prompt

Use this prompt when the user asks for a presentation using the shared AI presentation workflow.

## External Workflow

Reference:

- `https://github.com/georgep26/ai_presentations`

Read that repository's `AI_AGENT_GUIDE.md` before producing or editing presentations.

## Local Context

When the presentation describes this repo, read the relevant local docs first:

- `AGENTS.md`
- `README.md`
- `docs/deployment_process.md`
- `docs/config_structure.md`
- `docs/github_standards.md`
- `docs/frontend_interface.md`, when discussing frontend integration
- `docs/development_plans/`, when summarizing planned work

Do not duplicate long docs into presentation notes. Summarize and cite the local source files.
