# Diagram Prompt

Use this prompt when the user asks for a diagram using the shared AI diagram workflow.

## External Workflow

Reference:

- `https://github.com/georgep26/ai_diagrams`

Read that repository's `README.md` and `AI_AGENT_GUIDE.md` before producing or editing diagrams.

## Local Context

When the diagram describes this repo, read the relevant local docs first:

- `AGENTS.md`
- `README.md`
- `docs/deployment_process.md`
- `docs/config_structure.md`
- `docs/aws_naming_convention.md`
- `docs/frontend_interface.md`, for frontend/backend handoff diagrams
- `infra/infra.yaml`, for deployment topology diagrams

Do not invent architecture. Use the repo's docs and config as the source of truth.
